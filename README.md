Это адаптивная версия исходного магазина электроники TechStore из [КР №1](https://github.com/yeayaeyae/kr1-html-css-shop). Сохранены предметная область, пять страниц, названия и цены шести товаров, тексты магазина и фирменные цвета. Проект оформлен в отдельном репозитории. Bootstrap и другие CSS-фреймворки не используются.

Исходная версия — коммит 86ef309e239948dfbc1d54ec37f817134ac91c3c КР №1. В истории нового репозитория отдельно сохранён импорт исходного сайта. [КР №2 на Bootstrap](https://github.com/yeayaeyae/kr2-bootstrap-shop) относится к практикам №9–11 и остаётся отдельным проектом.

## Запуск

Откройте index.html в браузере. Все стили, скрипты и изображения локальные; сборка и установка зависимостей не нужны.

Для просмотра через HTTP при установленном Node.js:

    node scripts/serve.cjs

Адрес: http://127.0.0.1:4189. Остановка — Ctrl+C.

## Адаптивные решения

Основной подход — Mobile First: базовые правила рассчитаны на телефон, расширения реализованы через min-width.

| Ширина | Поведение |
|---|---|
| 360 и 430 px | Меню по кнопке, одна колонка товаров и полей, раскрываемые фильтры, характеристики в виде карточек |
| От 640 px | Две колонки товаров и полей формы, характеристики возвращаются к таблице |
| От 768 px | Открытая навигация на Flexbox, три преимущества в ряд |
| От 1024 px | Hero в две колонки, боковой sticky-фильтр, товар, заявка и контакты в две колонки |
| От 1280 px | Три карточки в строке каталога |

Сетки используют CSS Grid и minmax(0, 1fr), навигация и карточки — Flexbox. Длинные строки переносятся, изображения и поля ограничены контейнером. Горизонтальный скролл всей страницы не скрывается через overflow-x: hidden.

Таблица сохраняет caption, заголовки строк и столбцов, scope и явные роли. На телефоне строки превращаются в карточки; на широком экране возвращается табличный вид.

## Responsive images

Эмодзи заменены локальными иллюстрациями тех же категорий товаров.

- Карточки и товар используют picture, WebP с srcset 480/960, sizes и запасной формат SVG.
- Hero использует разные SVG-композиции для телефона и широкого экрана через source media.
- Изображения имеют содержательные alt, width и height; вне первого экрана используется loading=lazy.
- В CSS есть max-width: 100% и height: auto.

В проверке на 360 px браузер выбирал компактную композицию hero и WebP 480. Использованный вариант зависит от ширины слота и плотности пикселей.

## Доступность

- Skip-link — первый элемент при Tab; переводит фокус в main.
- Один h1 на странице, семантические header, nav, main, section, aside, footer.
- Текущая страница отмечена aria-current.
- Меню имеет aria-controls и aria-expanded, закрывается по Escape с возвратом фокуса, по ссылке и по нажатию вне шапки.
- При смене ширины фокус не остаётся в скрытом меню или фильтрах.
- Поля имеют label, autocomplete, подходящие типы и inputmode.
- Контрастный видимый фокус у ссылок, кнопок и полей, основные цели нажатия не меньше 44 px.
- Второстепенный текст затемнён до #4b5563.
- Нативный dialog с доступным названием и описанием удерживает фокус; Escape закрывает окно, фокус возвращается к кнопке.
- Счётчик товаров и результаты проверки формы объявляются через role=status.
- prefers-reduced-motion отключает анимации и плавную прокрутку.
- Без JavaScript навигация и содержимое остаются видимыми.

## Самостоятельные доработки

Мобильное меню с управлением клавиатурой, раскрываемые фильтры, совместная фильтрация категории и цены, пустое состояние и сброс, карточное представление таблицы, несколько способов адаптивных изображений, доступный диалог и перенос выбранного товара в заявку.

Исправлены ошибки исходной версии: случайный CSS внутри js/main.js и повторяющиеся стили контактов. Данные товаров вынесены из inline-скрипта в products.js.

## Проверки

Проверены все пять страниц на **360, 430, 768, 1024 и 1440 px** — 25 сочетаний страницы и ширины. Горизонтального скролла, битых изображений, HTTP-ошибок ресурсов и ошибок JavaScript не обнаружено.

Проверки axe-core по WCAG 2 A/AA и WCAG 2.1 AA на 360 и 1440 px для всех пяти страниц не выявили автоматических нарушений. Проверены меню клавиатурой, skip-link, удержание и возврат фокуса диалога, фильтрация, пустое состояние, выбор товара и форма.

Lighthouse **13.6.0**, категория **Accessibility**, мобильный экран 360 × 800, плотность 1, локальный HTTP-сервер:

| Страница | Accessibility | Отчёт |
|---|---:|---|
| Главная | 100/100 | [HTML](lighthouse/index-accessibility.html) |
| Каталог | 100/100 | [HTML](lighthouse/catalog-accessibility.html) |
| Заявка | 100/100 | [HTML](lighthouse/order-accessibility.html) |

В lighthouse/ сохранены исходные HTML- и JSON-отчёты и скриншоты. Автоматическая оценка не заменяет проверку клавиатурой и визуальную проверку. Подробности — в [журнале проверки](docs/verification.md).

## Формы

Проект учебный и статический. Формы используют встроенную проверку браузера и выводят её результат в доступную область. Сервер приёма заявок не подключён: данные не передаются и не сохраняются. Сообщение об успешной отправке не показывается.
